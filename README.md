# This project will be  maintained until the end of macOS Tahoe.
## This branch is intended for installing macOS Ventura & up. You can use it at other verion, But some features may be impacted.
# Device Specs
MSI GT-1763  
CPU:i7 4700MQ with Intel HD Graphics 4600  
Graphic: CardAMD Radeon RX 480 MXM 
Wireless: BCM94360HMB  

## Read before install
You have to set boot mode to UEFI with csm or you will meet display issues(8 Apple logos)  

# Working
Display (Both IGPU and DGPU)  
Eehernet  
Wi-Fi (Only broadcom cards)\
Sound

# Known issue:
Sleep/Wake
USB ports(USB 3.0 is working fine)
File Valut (Not tested yet)
Multiboot support for Linux distros 
Builtin camera (Need to download scm app and enable it using Windows)
Card reader(supposed to be working but not tested)  
HDMI out not working because of DGPU Vbios issue
